> 📌 原始素材来源：饼干哥哥 AGI 在 X 上分享的 AI 博主闭门会 20 条笔记（2026-11）。本文做了三件事：**重排结构、去掉幸存者偏差、标注时效性**。原汁原味想看原文，拉到文末有链接。

闭门会内容的典型问题是：所有人围炉夜话，大家各讲自己赚到钱的那一条经验，拼起来像一本圣经。但你照抄会死得很惨——因为**A 的高客单红利，可能正好踩在 B 的私域红线上**。

这一小时的任务：把 20 条经验**解构**，按"做什么业务 → 什么阶段 → 用哪条"归类，并给每条打三个标签：

- 🟢 **普适规律**：底层逻辑，几乎所有知识付费 / 自媒体业务都成立
- 🟡 **时效红利**：当下有效，3-6 个月后可能失效（视频号豆、投放预算风向等）
- 🔴 **幸存者偏差**：某个博主赚到了就当真理讲，样本小、未必复现

## 🎯 你将带走

- 一份按**业务阶段**重排的 20 条清单（从 0 到 1、从 1 到 10、从 10 到 N）

- 一个**后端飞轮画布**：自媒体 → 业务 → 内容 → 签单的闭环

## 第 1 步：先搞清楚闭门会的发言人在赚谁的钱（0–10 分钟）


闭门会说的是「AI 博主」——但 AI 博主内部至少分成 3 种商业模式，赚的钱完全不一样：

| 类型 | 主要收入来源 | 典型客单价 | 核心能力 |
|---|---|---|---|
| **A. 内容带货型** | 大厂 AI 工具投放 / 带货佣金 | 单条 5k–50k | 测评写作、爆款公式 |
| **B. 高客单陪跑型** | 社群 / 陪跑营 / 私塾 | 2k–5w / 人 | 教学体系、交付能力 |
| **C. B 端撮合型** | 咨询 / 项目分成 / 蓝皮书 | 10w–100w / 单 | 行业认知、关系网 |

20 条经验里**混合了这三种模式的实战**。如果你拿 A 型博主的「40 万粉不如 800 铁粉」去套 C 型业务，你会错过所有"大水漫灌拉认知"的机会；反过来用 C 型的"硅谷非共识深译"去做 A 型测评，你一个月出不了稿。

**行动**：在纸上写下，你现在**最想做哪种**？或者更现实的——**哪种你能撑得住 6 个月不赚钱**？

<Checkpoint>
你能用一句话说出：「我是 X 型博主，我的钱来自 Y 类客户，他们愿意为 Z 付费」吗？
<Answer>如果还不行，先把这步做完再往下读。不然后面 20 条你会每条都觉得"有道理"，然后什么都做不起来。</Answer>
</Checkpoint>

## 第 2 步：私域篇——精粉 > 泛粉，但要分清阶段（10–25 分钟）


### 原文对应条目：1、5、8、9、11

**条目 1（🟢 普适规律）**：40 万泛粉可能不如 800 个高净值铁粉。

这条是对的，但**只对后端有高客单产品的人成立**。如果你现在卖的是 99 元小课，800 人撑不起你的收入——这时候泛粉 + 分销模式反而更对。

精粉策略真正值钱的地方是：**让你有胆气砍掉 90% 的运营动作**。不做群发、不做日更、不做引流活动，只伺候那 800 人。

**条目 5（🟢 普适规律）**：没有后端团队，就把客单价一开始就定高。

这条和条目 1 是一对的。逻辑是：**你一个人能服务的人数有上限**。假设你一年能深度陪跑 100 人，那客单价就必须 ≥ 年收入目标 / 100。想赚 100 万，客单价至少 1 万起。

**条目 11（🟢 普适规律）**：先写"客户小传"再开社群。

创业发财的人和"二三线城市想少加班的白领"是**完全不同的两群人**，他们的痛点、付费意愿、互动方式都不一样。你的朋友圈、公众号文风、定价、交付节奏——全都要围着这一类人转。

**条目 8、9（🟡 时效红利 + 🟢 普适规律）**：引流动作要踩准平台红线。

这条本身是合规常识，但**具体方法（菜单栏藏码、企微黑名单共享）是和微信当下的风控策略绑定的**。半年后可能失效。原则不变，手段要常更。

### 这一步的动作

打开你现在的私域系统（哪怕只是一个微信好友列表），回答：

```
1. 我有多少个"真金白银买过我东西"的人？
2. 他们的平均客单价是多少？
3. 过去 90 天我和他们 1v1 聊过几次？
```

如果第 3 条是 0——你根本没有私域，只有一个通讯录。

<Checkpoint>
你能数出来谁是你的「铁粉」吗？不是点赞多的人，而是**付过钱 + 愿意主动找你聊 + 愿意被你写进案例**的那种。
<Answer>一般人数的下限是 **20 个**。少于 20 个，先别考虑搞社群分层、快闪群这些花活，先把这 20 个人伺候好再说。</Answer>
</Checkpoint>

## 第 3 步：变现篇——定价必须由渠道决定（25–40 分钟）


### 原文对应条目：3、4、6、14、17、19

**条目 4（🟢 普适规律）**：

```
公众号文末扫码直接付款：199–299 元上限
超过 1000 元：必须靠低价小课 + 直播 + 7 天陪跑体验
超过 1 万元：必须靠 1v1 咨询 / 线下见面
```

这是整篇笔记里**最值钱的一条**。它把定价从"我觉得我值多少"回到"渠道能承载多少决策成本"。

记住这张表。它适用于几乎所有知识付费 / 咨询类业务。

**条目 3（🟡 时效红利 + 🟢 结论对）**：C 端越来越难，往 B 端走。

结论对，但原文的论据有水分——"日活几亿的 AI 应用 C 端日营收不足百万"是以偏概全（豆包、元宝本来就靠流量变现而非付费订阅）。真实现象是：

- C 端用户**对 AI 工具的付费意愿低**（因为免费替代多）
- B 端用户**对 AI 落地的付费意愿高**（因为是刚需、能核算 ROI）

所以结论没错：**自媒体后端变现，往 B 端靠**。

**条目 6（🟢 普适规律）**：多级产品必须做"权益物理隔离"。

这条血泪。见过太多博主做了 2k / 2w / 5w 三档产品，结果 2k 会员天天在群里 at 你问问题，5w 会员觉得"我花的钱怎么和他一样效果"，最后两边都流失。

**解决办法只有一个**：把低价群的交付锁死在"文档 + 问答模板 + AI 机器人"，高价群锁死在"1v1 + 线下 + 老板私信"，物理隔离，永不越界。

**条目 14（🟢 普适规律）**：涨价是最好的催化剂。

利用**损失厌恶**。49 → 99 → 249 阶梯涨，每次涨价前搞一次限时优惠。这是 SaaS、知识付费、付费社群的通用打法。

**条目 17（🔴 幸存者偏差）**：走"向上社交"路线，深度编译硅谷非共识。

这条得打问号。能做好这件事的国内博主，**双手数得过来**。要求：

1. 有海外一线信源（SemiAnalysis、TechCrunch、HN 深度评论都算起步）
2. 能把英文观点翻译成**中文决策层的语境**（不是直译）
3. 有真实的 VC / 大厂 BD 关系网接单

如果你没有这三点，硬做只会变成"二手资讯搬运工"，不如老老实实做 B 型陪跑。

**条目 19（🟢 普适规律 + 🟡 时效）**：AI 套壳产品护城河浅。

半年被底层模型吃掉这个说法已经**是公认事实**。但"做出好用的 Skill 封装成小程序吃快钱"这个策略是时效的——窗口期大概还有 6-12 个月。

### 这一步的动作

画一张你现在的**产品矩阵图**：

```
┌─ 引流款（免费 / 9.9 / 49 元）──→ 筛选目标用户
├─ 入门款（199 / 299 元）────────→ 验证付费意愿
├─ 主力款（1980 / 4980 元）──────→ 主要利润来源
└─ 旗舰款（19800 / 49800 元）────→ 高客单 + 案例
```

缺哪一层，就补哪一层。不要全层都做，**挑你当前阶段最缺的 1-2 层**先补上。

<Checkpoint>
对照你现在的产品：定价是否符合"渠道决定定价"的规律？你有没有在公众号直接挂 1980 产品然后奇怪为什么没人买？
<Answer>最常见的错误：把高客单产品挂在低决策渠道卖。修复方法——要么降价到 299 以内，要么前面加一个"低价体验营"做转化漏斗。</Answer>
</Checkpoint>

## 第 4 步：投放与红利篇——视频号 + B 端预算的时间窗口（40–50 分钟）


### 原文对应条目：2、7

**条目 2（🟡 时效红利 + 🔴 需求待验证）**：

> 大厂金主预算正在从"AI 工具测评"转向"AI + 商业/财经"和"B 端落地故事"。

这条我认为**方向对、幅度存疑**。观察到的真实现象是：

- 2026 H1 国内 AI 工具账号投放确实非常饱和
- 大厂（豆包、元宝、Kimi、智谱）投放策略在从"认知拉新"转向"场景教育"
- "AI + 行业"账号的 CPM / 商单价格在上涨，但**整个盘子还在博弈**，不是已成定局

**行动建议**：

- 如果你**还没定方向**，优先选"AI + 某个你熟悉的 B 端行业"（财务、法务、HR、营销、工程、医疗任选其一）
- 如果你**已经在做工具测评**，别慌，用现有流量开始沉淀 B 端 case，慢慢转型
- **别为了追风口完全放弃现有业务**——风向还会再变

**条目 7（🟡 时效红利）**：视频号豆 + 视频号小店挂载知识星球。

这条当下是真的。微信在用全平台资源推视频号电商和知识付费，是**典型的红利期窗口**。但窗口期什么时候关？没人知道，可能 3 个月也可能 2 年。

**正确姿势**：

- 不All in，但要**有一只脚在视频号**
- 测试投豆的 ROI（标准：首次付费回本 ≥ 50% 就继续）
- 用小店挂星球，绕过微信群码的封号问题

**不要做的**：全部家当押视频号。见过太多人赌一个红利期把其他渠道都放弃，红利一过就归零。

### 这一步的动作

用 20 分钟做一个**红利窗口评分**：

```
对每个你在考虑的新动作（如投豆、发视频号），打三个分：
A. 做好了能带多少增量收入？（1-5 分）
B. 现在做比 6 个月后做领先多少？（1-5 分，越领先分越高）
C. 失败的代价是多少？（1-5 分，代价越低分越高）

A × B × C ≥ 40 的动作，优先启动。
```

<Checkpoint>
你有没有把"追风口"当成战略？风口是**战术层的选择**，战略层永远是"做哪群人的生意"。
<Answer>如果你的方向跟着风口来回换，你永远不会有复利。战略层 3 年不变，战术层 3 个月一调。</Answer>
</Checkpoint>

## 第 5 步：社群与运营篇——别把自己做死（50–58 分钟）


### 原文对应条目：10、12、13、15、16、18、20

**条目 10（🟢 普适规律）**：4+3 排期法——周一到周四你输出，周五到周日只允许互动。

**反对"日更即勤奋"的信念**。日更 3 个月后的典型结果：你被掏空、内容变水、用户审美疲劳。4+3 排期保留你的**产出节律和用户的消化节律**。

**条目 12（🟢 普适规律）**：把微信群当"荣誉奖励"而非标配。

颠覆直觉但非常对。大多数人买完社群之后，**根本不进群**。那你维护几百人的死群意义是什么？让每周排名前 5 的人才能进核心小群——这样：

1. 减轻你的运营成本
2. 制造稀缺感和参与动力
3. 小群质量奇高（因为都是最活跃的 5%）

**条目 13（🟢 普适规律）**：非物质激励（印作品集寄过去）。

20 块钱的淘宝印刷 + 10 块钱邮费 = 一个铁粉终身价值可能几千几万。**ROI 爆表**的运营动作。

类似的变体：寄手写卡片、给他写一篇专访、拉他进你的更高阶圈子。成本低、杀伤力大。

**条目 15（🟡 时效 + 🟢 方向对）**：用云端 Agent 给自己减负。

方向对——AI 运营正在成为标配。但具体工具（企微"大圆"、云端机器人挂 Skill）**有强绑定**，半年后可能换了一拨主流工具。

**原则**：任何**可重复 + 可规则化**的运营动作，都应该交给 AI。
- 新客询价识别 → AI
- VIP 消息漏回提醒 → AI
- 到期续费提醒 → AI
- 日报周报生成 → AI

**条目 16（🟢 普适规律）⭐**：自媒体是主业的"增长飞轮"，不是消耗品。

**这条是整篇笔记里仅次于定价公式的第二值钱**。

闭环：

```
主业实战 → 数据 / Case → 脱敏成内容 → 公众号发布 → 吸引精准客户 → 签单 → 新的实战
```

如果你把自媒体当主业，你一旦停更就归零。如果你把自媒体当飞轮，**停更一个月业务也不会死**（因为老客户还在转介绍）。

**条目 18（🟡 可行性待验证）**：OPC 超级个体组队——"项目主理人一票否决 + 公司留 40% + 贡献分红 60%"。

想法好，但**合伙的坑数不清**。见过的实际失败率 > 80%。原因：

- 利益分配总有人觉得不公平
- 决策权和执行权错位
- 蜜月期过后就是撕逼期

如果你现阶段靠一人独斗能赚到 ≥ 50 万 / 年，**先别急着合伙**。合伙适合"单打独斗撞到天花板 + 项目机会明确 + 对方是老朋友"三个条件同时成立。

**条目 20（🟢 普适规律）⭐**：AI 能跑完 80 分，最后 20 分是人类的审美和真诚。

这一条值得抄在工作台贴纸上。

AI 让**生产工业化内容的门槛归零**。意思是：所有人都能产出"及格"内容。这时候差异化只剩两样：

1. **审美**：你对信息的取舍、排版、配图、节奏感
2. **真诚**：你愿意暴露的脆弱、犹豫、真实感受

这两样 AI 短期内给不了。所以你如果全盘让 AI 写内容，你会和其他 1 万人一模一样。

### 这一步的动作

选出 20 条里对你当前阶段**最重要的 3 条**，写在便签上贴在显示器旁边。
不是"全部有道理"，是"这 3 条我这周就开始改"。

## 🧠 终极结论

20 条经验最终可以压缩成 **3 条根本原则**：

1. **定价由渠道决定，而不是价值感** —— 在你能承载的渠道层级里卖产品。
2. **自媒体是业务的飞轮，不是业务本身** —— 没有后端业务，内容再火也是消耗品。
3. **AI 把 80 分工业化，20 分的灵魂才是护城河** —— 别全盘让 AI 代笔，留下你自己的指纹。

其他 17 条都是这 3 条在不同场景的展开。
