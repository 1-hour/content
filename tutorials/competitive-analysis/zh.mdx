完成这一小时的学习后，你将掌握 5 维度框架（定位、功能、定价、用户体验、社区）进行竞品分析，并获得可重复使用的分析模板。

## 🎯 成果展示

一份覆盖 3 大竞争对手、5 个战略维度的全面竞品分析仪表板。你将获得：

- 带评分系统的完整分析表格
- 可视化竞争定位图
- 基于竞争差距的行动清单
- 可重复使用的研究模板

输出结构示例：
```
竞品分析：[你的产品类别]
├── 核心发现总结
├── 5 维度分析矩阵
├── 定位图（可视化）
├── 功能差距分析
└── 战略建议
```

## 📋 前置条件

- 能使用 Google Sheets 或 Excel
- 对自己的产品/市场有基本了解
- 能访问竞争对手网站和产品（需要时注册免费试用）
- 30 分钟不被打断的专注时间

## 第 1 步：搭建框架并选择竞争对手（0-15 分钟）

创建新表格，包含这些工作表：分析、评分、行动清单。

在分析表中创建以下结构：

```
第 1 行：表头
A1: 竞争对手 | B1: 定位 | C1: 核心功能 | D1: 定价 | E1: UX 评分 | F1: 社区 | G1: 总分

第 2-4 行：你的 3 大竞争对手
第 5 行：你的产品（用于对比）
```

按以下标准选择 3 个主要竞争对手：
- 直接竞争对手（相同目标用户 + 问题）
- 间接竞争对手（不同解决方案，相同问题）
- 标杆竞争对手（你希望 2 年后达到的水平）

在 H2-H4 单元格中写下选择每个竞争对手的原因。

<Checkpoint>
你是否选择了 3 种不同类型的竞争对手，代表不同的战略威胁？
<Answer>是的，一个直接竞争对手针对相同客户，一个间接竞争对手用不同方式解决相同问题，还有一个是该领域的标杆企业</Answer>
</Checkpoint>

## 第 2 步：研究定位和功能（15-30 分钟）

对每个竞争对手，访问其首页并记录：

**定位分析：**
- 主标题和价值主张
- 提及的目标用户
- 声称的核心差异化优势
- 消息传递语调（企业级 vs 消费级，技术性 vs 简单）

**功能分析：**
汇总所有竞争对手的功能创建总功能清单，然后标记每家提供哪些功能：

```
功能清单示例：
- 实时协作：竞争对手 A (✓), 竞争对手 B (✗), 竞争对手 C (✓)
- 移动应用：竞争对手 A (✓), 竞争对手 B (✓), 竞争对手 C (✗)
- API 接入：竞争对手 A (✗), 竞争对手 B (✓), 竞争对手 C (✓)
```

专注于对目标用户重要的功能，而非他们提供的所有功能。

<Checkpoint>
你能否用一句话清楚阐述每个竞争对手的主要价值主张？
<Answer>是的，每个竞争对手都有独特的定位角度，将他们与其他竞争对手区分开来</Answer>
</Checkpoint>

## 第 3 步：分析定价、用户体验和社区（30-45 分钟）

**定价研究：**
记录其定价结构：
- 免费版限制
- 付费版定价和功能
- 企业/定制定价说明
- 付费模式（月付/年付折扣）

**用户体验评估（每个产品花 5 分钟使用）：**
注册免费试用并评估这些要素（1-5 分评分）：
- 引导流程清晰度
- 界面简洁性
- 任务完成便捷性
- 移动端体验（如适用）

**社区分析：**
检查其社区活跃度：
- 社交媒体关注者和互动量
- 用户生成内容数量
- 社区论坛/Slack 活跃度
- 客户推荐和案例研究

<Checkpoint>
你是否实际使用了每个竞争对手的产品至少 3 分钟来评估用户体验？
<Answer>是的，我完成了每个平台的注册流程并测试了核心功能</Answer>
</Checkpoint>

## 第 4 步：为竞争对手评分并制作定位图（45-55 分钟）

为每个维度创建评分系统（1-5 分）：

**评分标准：**
- 定位：清晰度和差异化程度（5 分 = 价值主张清晰独特）
- 功能：对目标用户的完整性（5 分 = 具备用户需要的全部功能）
- 定价：性价比（5 分 = 物超所值，定价有竞争力）
- 用户体验：易用性和设计（5 分 = 令人愉悦、直观的体验）
- 社区：强度和参与度（5 分 = 繁荣活跃的社区）

汇总每个竞争对手的得分。

**创建可视化定位图：**
绘制 2x2 网格：
- X 轴：价格（低到高）
- Y 轴：功能复杂度（简单到高级）
- 将每个竞争对手标为圆圈
- 圆圈大小代表社区强度

这能揭示市场定位空白和机会。

## 第 5 步：完成分析（55-60 分钟）

基于分析生成 3-5 个行动项：

**行动项示例：**
- 定价：将入门级计划降价 20% 以匹配竞争对手 B
- 功能：开发移动应用以符合市场标准
- 定位：更清楚地强调我们独特的自动化优势
- 用户体验：简化引导流程（他们的需要 2 分钟，我们的需要 8 分钟）
- 社区：像竞争对手 C 一样开始每周用户展示

通过创建相同结构的空白版本将表格保存为模板。

🎉 你现在拥有了系统性的竞品分析和可重复使用的市场研究框架。
